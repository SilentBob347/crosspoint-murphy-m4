# Repository Working Agreement

This is Daniel's personal CrossPoint Murphy repository. Read and follow
`MAINTENANCE.md` before making changes.

- Work only in this repository unless Daniel explicitly expands the scope.
- Keep `main` usable for the Murphy M4 and preserve its hardware support.
- Prefer focused cherry-picks or adaptations from CrossPoint Reader and CrossInk
  Reader; keep personal changes in focused commits.
- Keep `freeink-sdk` pointed at a specific, publicly reachable commit in the
  official FreeInk SDK repository. Do not modify the SDK unless explicitly asked.
- Build and package releases using the `murphy_m4` PlatformIO environment.
- Do not push, tag, publish releases, or change remotes without explicit approval.
